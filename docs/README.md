# Documentação do projeto

- [CHANGELOG.md](CHANGELOG.md) – registro de tudo que foi alterado, commit a commit (mais recente primeiro).
- [DECISOES.md](DECISOES.md) – por que as escolhas foram feitas (hospedagem, estrutura, domínio).
- [DOMINIO-E-DNS.md](DOMINIO-E-DNS.md) – como o domínio aponta para o GitHub Pages e como verificar.
- [PENDENCIAS.md](PENDENCIAS.md) – o que ainda falta fazer.

## Regras de manutenção
1. Todo commit tem mensagem descritiva (o quê e por quê).
2. Todo commit gera uma entrada no `CHANGELOG.md`, com data, hash, arquivos e motivo.
3. Decisões que mudam a estrutura entram também em `DECISOES.md`.
4. Pendências resolvidas saem de `PENDENCIAS.md` e viram entrada no `CHANGELOG.md`.
